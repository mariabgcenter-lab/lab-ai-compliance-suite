# Laboratory AI & Quality Control Suite

🚀 **Live Interactive App:** [Launch Dashboard] (https://lab-ai-compliance-suite-icr9e9zehffzgw8qj4fdb2.streamlit.app/)
An interactive Streamlit application designed for clinical diagnostics, industrial QA/QC, and ISO-compliant laboratory workflows.

## Included Modules
1. **ISO Compliance & SOP Audit Assistant:** Scans technical reports for missing parameters.
2. **Biofilm Live/Dead Analyzer:** Processes dual-channel fluorescence images using watershed segmentation.
3. **Diagnostic Batch QC Validator:** Enforces system suitability checks and exports QA batch release reports
