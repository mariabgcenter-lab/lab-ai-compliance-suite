# Laboratory AI & Quality Control Suite

🚀 **Live Interactive App:** https://lab-ai-compliance-suite-icr9e9zehffzgw8qj4fdb2.streamlit.app/

An interactive Streamlit application designed for clinical diagnostics, industrial QA/QC, and ISO-compliant laboratory workflows.

## Included Modules
1. **ISO Compliance & SOP Audit Assistant**  
   Scans technical reports and SOPs for missing parameters and common compliance gaps.
2. **Biofilm Live/Dead Analyzer**  
   Processes dual-channel fluorescence images using watershed segmentation and reports live/dead ratios.
3. **Diagnostic Batch QC Validator**  
   Enforces system suitability checks and exports QA batch release reports.

## Quick features
- Interactive **Lab Risk Assessment** with sliders and a transparent risk score.
- Visual breakdown of risk components using a bar chart.
- Document upload and rule‑based flags (planned/optional).
- Simple task creation for training and audit tracking (planned/optional).
